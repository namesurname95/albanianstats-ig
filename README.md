# albanianstats-ig

Images mirrored to Instagram from posts already published by [@albanianstats](https://x.com/albanianstats) on X.

- `queue/<batch>/` images and captions, pushed from the private albanianstats_agent repo (`tools/ig_post.py`)
- `publish.py` + `.github/workflows/publish.yml` publish the next one every morning at 08:30 Paris time
- `posted.jsonl` what has been published
